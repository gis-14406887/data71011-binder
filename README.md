# DATA71011 Binder exercise

Week 5 reproducibility exercise, following The Turing Way's [Zero-to-Binder tutorial](https://book.the-turing-way.org/communication/binder/zero-to-binder/).

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/gis-14406887/data71011-binder/main)

## Run the example

1. Click the Binder badge and wait for JupyterLab to open.
2. Open a Terminal from the Launcher.
3. Run `python hello.py`.

Expected output: `Hello from Binder!`

`requirements.txt` pins NumPy to version 1.25.0.

Changes made inside Binder are temporary and are not automatically saved back to GitHub. Download any notebook you want to keep and upload it to this repository.
